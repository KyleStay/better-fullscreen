Better Fullscreen

Help

Use a website video's fullscreen button to fill the current tab. Press Esc or choose Return to page to go back.

Choose Native fullscreen in the media view to use the whole display. Unsupported players use normal fullscreen.

Built-in Chrome video controls and some embedded players may still use native fullscreen. Turn this off for any site that does not work well. Reload open pages after installing or updating the extension.
