# Better Fullscreen

Better Fullscreen presents website media within the current browser viewport, with native fullscreen available explicitly.

## Language

**Media view**:
A video player's expanded presentation occupying the current browser viewport.
_Avoid_: Media popup

**Viewport mode**:
The media view within the existing tab, with the browser window's size and position unchanged.
_Avoid_: Native fullscreen

**Native fullscreen**:
Chrome's genuine fullscreen presentation, which can use a macOS fullscreen Space.
_Avoid_: Viewport mode

**Media fullscreen request**:
A website's request to expand a media player into a fullscreen view.
_Avoid_: Browser fullscreen command

**Site override**:
A user's choice to leave a particular website's normal fullscreen behavior enabled.
_Avoid_: Global disable

**Return to page**:
Ending the expanded media presentation and restoring the page's original layout.
_Avoid_: Close video, Return to tab
